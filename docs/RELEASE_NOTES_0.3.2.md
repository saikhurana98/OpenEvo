# OpenEvo v0.3.2

Motion polish for OpenEvo's dense native EVO 4 console.

## What's new

- Inspectors slide and fade in, with outgoing content retained during the exit.
  Rapid switching, closing and reopening resolve to the latest requested panel.
- Console cards, dials and mixer strips ease between responsive layouts.
- Buttons have subtle hover, focus and press feedback with stable hitboxes;
  encoders and sliders also highlight interaction.
- Windows' client-area animation preference is respected at startup. Reduced
  motion skips decorative transitions and setpoint interpolation; the existing
  audio meter ballistics are retained.
- Covered and exiting controls cannot accept edits. Actual values and hardware
  commands remain immediate, and animation emits no intermediate commands.

## Download

Extract **OpenEvo-0.3.2-windows-x64.zip** and run **OpenEvo.exe**.
Application source, build instructions, notices and an internal checksum
manifest are included. The separate **SHA256SUMS.txt** verifies the ZIP itself.

## Validation

- 24 ordinary Rust release tests pass.
- The offscreen software-renderer regression checks 17 continuous controls
  with 34 rollback/readback assertions, transition interpolation, stable
  hitboxes, rapid navigation, reduced motion and covered/exiting input guards.
- Five logical window sizes and all four compact inspectors are checked.
- Decorative animations stop when settled; no extra control callbacks are
  generated by animation or responsive layout changes.

These motion checks use a simulated device and an in-memory renderer. They
create no desktop window and do not call the device API. Native visual review
and live hardware tests were not repeated for this version. Driver, routing,
worker and audio meter logic are unchanged from 0.3.1.

## Requirements and known limits

Windows x64, one connected Audient EVO 4, and the official installed Audient
driver. The verified API DLL is version 5.70.0.0 with SHA-256
`25af306d32bb674796bfe82ba220396254d97e8859e024394fbeda7db242b2e6`.
Other models and unverified DLLs are rejected. The executable is unsigned.

Loopback routing is write-only, saved routes are not replayed on startup or
reconnect, and playback activity is not a post-volume analog output meter.
Use Audient's official updater for firmware. Existing EvoControl cache data
is preserved. Analog click-free output, sleep/resume and hours-long streaming
remain unverified.
